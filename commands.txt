1. npm commands: 

    i. Check version of npm:
        npm -v

    ii. Download node package with npm: 
        npm i <package>

2. node commands:

    i. Check version of node:
        node -v

    ii. Run node file:
        node <filename>

3. nest JS commands:

    i. Download nest JS through npm (globally):
        npm i -g @nestjs/cli

    ii. Check version of nest:
        nest -v

    iii. Start nest JS project:
        npm run start,
        nest start,
        nest start <app-name>

    iv. Start nest JS project in development mode:
        npm run start:dev,
        nest start --watch
        nest start <app-name> --watch

4. nx commands:

    i. Create new microservice:
        nx g @nrwl/nest:app <service_name>

    ii. Start microservice:
        nx s <service_name>

5. typesense commands:

    i. Download typesense-server within docker:
        docker pull typesense/typesense:26.0

    ii. Run typesense server within docker
        docker run -p 8108:8108 -v /typesense-data:/data typesense/typesense:26.0 --data-dir=/data --api-key=xyz --enable-cors

    iii. Download typesense package using npm:
        npm i typesense

6. meilisearch commands: 

    i. Download meilisearch-server to docker
        docker pull getmeili/meilisearch:v1.7.3

    ii. Run meilisearch-server within docker
        docker run -it --rm -p 7700:7700 -e MEILI_MASTER_KEY='xyz' getmeili/meilisearch:v1.7.3

    iii. Download meilisearch package using npm:
        npm i meili
    
7. git commands:

    i . Initialize new Git repository in the current directory:
        git init

    ii. Cloning existing repository from Git to Local:
        git clone {url}

    iii. Add files to staging area for next commit:
        git add <file_name>,
        git add . (for all files)

    iv. Commit changes with message from staging area:
        git commit -m "commit_message"

    v. Display the status of working directory and staging area:
        git status

    vi. Show the difference between working directory and staging area:
        git diff

    vii. Fetch changes from remote repository's main branch and merges them to current branch:
        git pull origin main

    viii. Push the committed changes from local main to remote repository's main:
        git push origin main

    ix. List all local branches:
        git branch

    x. Create new branch and switch to it:
        git checkout -b <branch-name>

    xi. To merge changes from one_branch to current_branch:
        git merge <one_branch>

    xii. Reapplies commits from the current branch on top of the main branch:
        git rebase main

    xiii. Display history of commits in the repository:
        git log

    xiv. Lists all the remote repositories associated with the current repository along with their URLs:
        git remote -v

    xv. Temporarily shelves changes that are not ready to be committed:
        git stash save "Work in progress"

    xvi. Create a lightweight tag named v1.0 at the current commit:
        git tag v1.0

    xvii. Download objects and refs from the remote repository named origin:
        git fetch origin

    xviii. To set the global configuration value for the user's name: 
        git config --global user.name "Santhosh_Veerabathiran"

8. powershell commands:

    i. Change Execution policy in powershell:
        set -ExecutionPolicy RemoteSigned => Y
