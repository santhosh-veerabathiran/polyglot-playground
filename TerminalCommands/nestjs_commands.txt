1. Download nest JS through npm (globally):
    npm i -g @nestjs/cli

2. Check version of nest:
    nest -v

3. Start nest JS project:
    npm run start,
    nest start,
    nest start <app-name>

4. Start nest JS project in development mode:
    npm run start:dev,
    nest start --watch

5. Start nest JS mono-repo project in development mode:
    nest start <app-name> --watch

6. New workspace:
    nest new <app-name>

7. New monorepo app:
    nest g app <app-name>

8. New library
    nest g lib <lib-name>
