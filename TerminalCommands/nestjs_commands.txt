i. Download nest JS through npm (globally):
    npm i -g @nestjs/cli

ii. Check version of nest:
    nest -v

iii. Start nest JS project:
    npm run start,
    nest start,
    nest start <app-name>

iv. Start nest JS project in development mode:
    npm run start:dev,
    nest start --watch
    nest start <app-name> --watch
