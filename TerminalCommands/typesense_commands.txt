i. Download typesense-server within docker:
    docker pull typesense/typesense:26.0

ii. Run typesense server within docker
    docker run -p 8108:8108 -v"$(pwd)"/typesense-data:/data typesense/typesense:26.0 --data-dir=/data --api-key=xyz --enable-cors

iii. Download typesense package using npm:
    npm i typesense
